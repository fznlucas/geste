# Screen specs

One file per area. Each screen lists: boards, purpose, layout, components, data, states, events, acceptance criteria. Exact words for every screen are in `reference/copy/<Board>.txt` (extracted from the canvas in its default state) — use them verbatim.

| File | Screens |
| --- | --- |
| `store.md` | Layout, Home, Shop, Work page, Shopping list, Prints, Gift cards, Method, About, Journal, Help, Legal, Tracking, 404 |
| `checkout.md` | Cart drawer, Checkout (4 steps + outcomes) |
| `account.md` | Login, Register, Library, Orders, Settings |
| `reader.md` | Guide reader (step, timer, print), PWA |
| `admin.md` | All admin screens (desktop + phone) |
